CommitJourney 是一个用于导出 Git 历史记录与每日提交统计信息的小型 Windows 工具软件。

本软件使用 C# 编写，并基于 Windows Forms 开发。项目开发过程中使用了 [::bi:openai:: ChatGPT](https://chatgpt.com) 进行辅助生成与功能实现，本人主要负责功能设计、UI 设计与项目维护工作。

项目已开源于 [::mdi:github:: GitHub](https://github.com/mcenahle/CommitJourney)，并采用 [MIT License](https://github.com/mcenahle/CommitJourney/blob/main/LICENSE) 开源许可证。

## 当前功能

- 导出 Git Log
- 导出每日 Commit 统计 CSV
- 自定义仓库路径
- Windows 独立 exe 发布
