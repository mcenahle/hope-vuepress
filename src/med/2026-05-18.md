## 二、排卵后为什么基础体温会升高？

- [ ] 排卵后为什么P4升高？
- [ ] 为什么月经会“撤退性出血”？

![为什么基础体温会升高？](/images/med/2026-05-18-1.png)

**原理**：黄体形成，P4上升，于是体温设定值上调，即基础体温升高。所以就会出现：基础体温升高约 0.3～0.5℃，并持续在“高温相”。这个变化其实不算特别大，但很稳定。

于是女性体温会出现“双相体温”，大致会变成：

|  阶段   |    体温特点    |
|:-----:|:----------:|
|  排卵前  |     较低     |
|  排卵后  |     升高     |
| 月经来潮前 | 若未怀孕，则再次下降 |

|  体温表现  |  可能提示   |
|:------:|:-------:|
|  一直低温  |  可能未排卵  |
| 排卵后升高  |  黄体形成   |
|  高温持续  |  可能怀孕   |
| 月经前下降  |  黄体退化   |

:::
答案：

   1-2  C B
   3-4  B C
5. 这是因为排卵后，黄体出现，导致 P4 上升。此时身体会提高体温设定值，从而导致体温略微提升。
   而月经前，黄体消失，P4 也随即下降。同理体温也随之下降。
