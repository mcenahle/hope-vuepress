## 我在做什么
目前主要在进行网页开发。我习惯把网站当作“活着的东西”去维护。

它们会有故障、会变慢、会需要照顾，也会随着时间不断成长。而我喜欢处理这些细小却长期存在的问题。

**所以相比“程序员”这个称呼，我有时更愿意把自己称作“计算机护士”。**

或许我做的事情并不耀眼，但我希望自己维护的网站，能够稳定、安静地运行很久。
